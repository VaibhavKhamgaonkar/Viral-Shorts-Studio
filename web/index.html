Set up YouTube

  1. Create the sign-in file

    Sign in with the Google account that manages your channel. Choose Desktop app, continue, then click Download JSON before closing the confirmation.

    Open Google’s personal setup
    Using an existing Google Cloud project?

    For an External project, use Google Auth Platform → Clients to create a Desktop app client. For a project in Testing, add your Google account under Audience → Test users.

  2. Enable YouTube uploads

    Select the same project at the top of Google Cloud, then click Enable on the YouTube Data API v3 page.

    Open YouTube Data API v3

  3. Connect your channel

    Select the downloaded JSON file below. Then sign in with Google and approve both requested permissions.

Set up Facebook & Instagram

  1. Choose a User Access Token

    In the Explorer’s right-hand panel, select your app under Meta App. Under User or Page, open the dropdown that says Get Token, then choose Get User Access Token.

    Open Graph API Explorer

  2. Add publishing permissions

    Stay in the Permissions tab. Use Add a Permission for each entry you need.

    • For either platform pages_show_list and pages_read_engagement
    • For Facebook add pages_manage_posts
    • For Instagram add instagram_basic and instagram_content_publish
    Only seeing business_management and pages_show_list?

    Open Meta My Apps and select the same app. Under Use cases, find Manage everything on your Page and click Customize. In Permissions and features, add pages_read_engagement and pages_manage_posts. If the Page use case is missing, check Add use cases.

    For Instagram, set up Instagram API with Facebook Login in the app dashboard and make instagram_basic and instagram_content_publish available. Link a professional Instagram account to your Facebook Page.

    Return to Explorer, reselect your app, and generate a fresh User Access Token with the added permissions.

  3. Generate and copy your token

    Click Generate Access Token in the right-hand panel. If it is greyed out, select Get User Access Token first. In the Facebook prompt, continue as the account that manages your Page and grant access to that Page if Meta asks. Back in Explorer, click the copy icon beside the Access Token field above the blue button.

  4. Connect your Page in the studio

    Paste the copied token below and click Find my Pages. Choose your Page by name, then click Connect this Page.
